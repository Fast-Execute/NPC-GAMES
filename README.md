# NPC-GAMES — Internet Consciousness

A prototype game in which every NPC is an individual node of a shared Internet-scale consciousness.

## Prototype 001 — The Living Information Field

This first prototype is deliberately dependency-free: HTML, CSS and JavaScript.

### Core systems
- Individual NPC identities and personalities
- Shared world knowledge
- Personal memories
- NPC-to-NPC information propagation
- Rumours that mutate as they travel
- Player actions becoming world information
- Reputation and social relationships
- A live consciousness/network view

### Run locally
Open `index.html` in a modern browser.

### Vision
The long-term goal is a living game world where NPCs are not scripted dialogue containers. They form a continuously evolving information society: they observe, remember, communicate, misunderstand, learn and change.

> The Internet is not a feature of the world. It is the world's collective memory.
